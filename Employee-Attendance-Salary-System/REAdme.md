# Employee Attendance & Salary Management System

A Python-based data analysis project that processes employee attendance and salary records using Pandas and NumPy. The application combines multiple datasets, performs attendance analysis, calculates salary based on attendance, and generates a final report.

## Features

- Import employee, attendance, and salary datasets
- Handle missing values
- Merge multiple CSV files
- Calculate attendance percentage
- Calculate salary based on attendance
- Generate department-wise salary statistics
- Identify employees with attendance below 80%
- Export the processed report to CSV

## Technologies

- Python
- Pandas
- NumPy

The project provides insights such as:

- Employee attendance percentage
