# 🏠 House Price Prediction

## About

This is a Machine Learning project that predicts house prices using the Linear Regression algorithm. The model is trained on housing data and predicts the price based on different house features.

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook (VS Code)

## Dataset

- housing.csv

## Features

- Longitude
- Latitude
- Housing Median Age
- Total Rooms
- Total Bedrooms
- Population
- Households
- Median Income

- Ocean Proximity

## Model

- Linear Regression

## Project Files

- `housing.csv`
- `prediction_code.ipynb`
